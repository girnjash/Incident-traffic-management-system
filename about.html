About IncidentX

A basic website concept for reporting and viewing traffic incidents.

Our Purpose

Traffic incidents can cause delays and create safety problems. IncidentX is a student project that shows how incident information can be organised on a website.

How It Works

1. Report

Enter the category, severity and location of an incident.

2. View

See sample incident details on the incidents page.

3. Locate

Use the map page to view the map of India.

4. Respond

Understand how incident information may help response teams.

Technologies Used

  • HTML - used to create the structure of web pages.
  • CSS - used to style the pages and arrange the content.
  • OpenStreetMap - used to display a map in the browser.

Project Note

This version is made with HTML and CSS only. Forms, live updates, login validation and automatic incident tracking are not active because JavaScript has been removed.
